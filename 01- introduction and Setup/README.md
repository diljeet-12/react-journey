# 📘 01 - React Introduction & Setup

## What is React?

React is a JavaScript library for building fast, interactive, and reusable user interfaces (UI). It was developed and is maintained by **Meta (formerly Facebook)**. React follows a **component-based architecture**, allowing developers to build applications using reusable UI components.

## Why React?

React helps developers:

- Build dynamic and interactive user interfaces
- Create reusable components
- Write clean and maintainable code
- Develop Single Page Applications (SPAs)
- Improve application performance and user experience

## What is a Single Page Application (SPA)?

A **Single Page Application (SPA)** loads a single HTML page and updates only the required content instead of reloading the entire page.

### Benefits

- Faster page navigation
- Better user experience
- Smooth interactions

### Examples

- Facebook
- Instagram
- Gmail
- Netflix


## What is a Component?

A **component** is a reusable piece of the user interface.

Example:
Website
├── Navbar
├── Hero Section
├── Product Card
└── Footer

Each section can be developed independently and reused throughout the application.

## What is Node.js?
Node.js is a JavaScript runtime that allows JavaScript to run outside the browser.
It is used in React development to:
- Create React projects
- Install packages
- Run the development server
- Build production-ready applications

## What is npm?
**npm (Node Package Manager)** is the default package manager for Node.js.

It is used to:
- Install packages
- Manage project dependencies
- Run project scripts

Example:
```bash
npm install react
```

## Key Takeaways
- React is a JavaScript library for building user interfaces.
- React uses reusable components.
- React is commonly used to build Single Page Applications.
- Node.js provides the development environment.
- npm manages project dependencies and packages.
